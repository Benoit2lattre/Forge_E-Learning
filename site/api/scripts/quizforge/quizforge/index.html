scripts.quizforge.quizforge#

QuizForge — banques de questions Moodle à partir d’Excel ou de GIFT.

Commandes principales

python quizforge.py convertir Quizz.xlsx [autres fichiers…] [--categorie MMC/TP3] [--sortie dossier]
    Excel, GIFT (.txt) ou banque (.yaml) -> GIFT par catégorie + Moodle XML + banque YAML + rapport.
python quizforge.py importer dossier_ou_fichiers… --banque banque.yaml
    Reprend des fichiers GIFT / Excel existants dans une banque YAML unique, dédoublonnée.
python quizforge.py modele [--sortie modele_QuizForge.xlsx]
    Crée un classeur modèle avec un onglet par type de question.
python quizforge.py profils [Ecole1]
    Liste les profils d'établissement, ou affiche les réglages de l'un d'eux.

Autres commandes : valider (vérifier classeurs, projets du pointeur et profils), bilan (DiagForge : analyse des résultats d’un test Moodle), reparer, fusionner et assistant (menu pas à pas) ; python quizforge.py --help les décrit toutes.

Option --profil Ecole1 (convertir, importer) : barème, types autorisés, formats, langues et charte lus dans profils/Ecole1/profil.yaml ; les options de la ligne de commande l’emportent.

Types gérés : vf (vrai/faux), qcm (une ou plusieurs bonnes réponses), appariement, courte (réponse courte), numerique (avec tolérance), essai (réponse libre), et en Moodle XML seulement schema (glisser-déposer sur image) et trous (texte à trous).

Commande modele : crée le classeur modèle (ou un classeur vide), sans écraser un fichier existant sauf avec --ecraser.

scripts.quizforge.quizforge.CLES_PROFIL#
scripts.quizforge.quizforge.valider_profil(f: pathlib.Path) → list#

Vérifie un fichier de profil (YAML lisible, clés connues, valeurs comprises) et renvoie la liste des problèmes.

scripts.quizforge.quizforge.valider_projet(f: pathlib.Path) → list#

Vérifie un projet du pointeur (JSON) et renvoie la liste des problèmes : type, image, zones, énoncé, leurres.

scripts.quizforge.quizforge.cmd_valider(a)#

Commande valider : vérifie classeurs, projets du pointeur et profils, sans rien écrire.

Signale aussi les points d’écriture à vérifier dans les questions (rétroaction absente, indices qui trahissent la clé, défauts d’écriture : voir qualite).

scripts.quizforge.quizforge.cmd_bilan(a)#

Commande bilan (DiagForge) : bilan des résultats d’un test Moodle (exports Notes + Réponses) → classeur d’analyse.

La couleur principale et le mode de tirage sont pris dans le profil s’il y en a un (voir bilan.bilan()).

scripts.quizforge.quizforge.noter_version_bilan(a)#

Reconnaît la version QuizForge du test d’après les noms des questions de l’export XML (registres des cours), l’écrit dans le bilan (onglet « Version ») et inscrit le bilan au registre.

Commande profils : liste les profils, ou affiche les réglages complets de l’un d’eux ; régénère les index.

Lance l’assistant : menu pas à pas où chaque choix se fait par un numéro.

scripts.quizforge.quizforge.preparer_arguments(argv)#

Prépare les arguments de la ligne de commande avec une saisie tolérante de la commande.

« con », « -c », « C », « Convertir »… sont compris ; un fichier seul (glissé sur QuizForge.bat) vaut convertir. Sans argument, renvoie ["--help"].
