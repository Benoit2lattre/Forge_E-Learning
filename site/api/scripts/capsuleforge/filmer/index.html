scripts.capsuleforge.filmer#

CapsuleForge — enregistreur intégré : écran, micro et webcam en même temps (Windows), puis import dans un chapitre.

Commande :

capsuleforge filmer <chapitre> --section partie/section [--titre "…"] [--ecran 1] [--webcam [NOM]] [--micro NOM | --sans-micro]
                    [--ips 20] [--duree s] [--sans-import] [--appareils]

Raccourcis (comme l’enregistreur de didacticiel) : Ctrl+Maj+P pause / reprise (2 bips), Ctrl+Maj+F fin (3 bips) ; dans la fenêtre de commande, Entrée termine aussi ; une ligne « pause » met en pause ou reprend (boutons de l’Atelier Forge). Un compte à rebours de 3 s précède l’enregistrement.

Chaque source a son fil ; chaque image et chaque morceau de son reçoit l’instant de l’horloge commune (pauses retirées) : l’écran, la webcam et la voix restent calés, même si une source démarre en retard (le micro met environ une seconde à s’ouvrir : le début du son est complété par du silence). Fichiers bruts dans <chapitre>/enregistrements/<date>/ (ecran_<date>.mp4, micro_<date>.wav, camera_<date>.mp4, journal.txt), puis import comme capsuleforge video … --son micro.wav : pas vidéo découpés aux silences ; la webcam devient le caméo de ces pas. Appareils : DirectShow (noms lus dans le journal de ffmpeg) ; écrans : mss. --appareils les liste. Essai sans appareils (toutes plateformes) : --essai (mire et son synthétiques). Licence : GPL v3.

Attributes#

TAUX

Classes#

Horloge

Temps utile de l'enregistrement : depuis le départ, pauses retirées.

Video

Une source d'images (écran ou webcam) -> MP4 H.264, chaque image à son instant (cadence variable).

Micro

Le micro -> WAV mono 48 kHz ; le début est complété par du silence pour être calé sur l'horloge commune.

Renvoie les listes (caméras, micros) des appareils DirectShow.

Filme l’écran, le micro et la webcam demandés dans dossier jusqu’à la fin demandée.

La fin vient du raccourci Ctrl+Maj+F, de la touche Entrée ou de duree (secondes utiles). Écrit les fichiers des sources et journal.txt ; renvoie le dictionnaire des chemins écrits (clés ecran, micro, camera selon les sources). essai=True remplace les appareils par des sources synthétiques.

Filme dans enregistrements/<date_heure>/ du chapitre puis importe la vidéo dans la section.
