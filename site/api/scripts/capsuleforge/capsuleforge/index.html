scripts.capsuleforge.capsuleforge#

CapsuleForge — chapitres de cours interactifs et capsules de simulation logicielle, décrits par un fichier YAML.

Commandes (abréviations acceptées : « en », « ed », « cons », « conv », « v »…) :

python capsuleforge.py enregistrer freecad_pad [--titre "FreeCAD : premier corps"] [--ecran 1]
    Enregistre une manipulation (Windows). Ctrl+Maj+E = nouvelle étape, Ctrl+Maj+P = pause, Ctrl+Maj+F = fin.
    Sortie : data/capsuleforge/freecad_pad/ (journal.jsonl, images/, capsule.yaml).
python capsuleforge.py editer freecad_pad
    Ouvre l'éditeur visuel dans le navigateur (image, zone, bulle, chronologie, ajout d'éléments).
python capsuleforge.py construire freecad_pad [--largeur 1920] [--format webp]
    capsule.yaml -> dist/capsuleforge/freecad_pad/index.html (lecteur « Regarder » / « À vous »).
python capsuleforge.py construire fiabilite
    Un dossier sans capsule.yaml mais avec chapitre.yaml (cours) : lecteur du chapitre (plan, parcours, sous-titres,
    apparitions, spots, pointeurs), images en WebP et sons en MP3.
python capsuleforge.py construire fiabilite --scorm chapitre|parties|tout [--scorm-version 1.2]
    En plus : paquets SCORM 2004 pour Moodle (un pour le chapitre, un par partie du tronc, ou les deux).
python capsuleforge.py construire demo_traction --cours traction[:ecole1-meca[/2026]]
    Capsule habillée pour l'édition (charte, logo et textes du profil de l'école, titre, codes, promo ; filigrane si
    l'édition le demande), rangée comme version de l'édition (capsules/<capsule>/v1/) et inscrite au registre.
python capsuleforge.py pdf fiabilite [--langue en] [--contenu diapos|texte|diapo|texte,diapo] [--notes marge] [--paquet oui]
    Une version du PDF à partir du lecteur construit (pdf/fiabilite_en_texte.pdf…) ; --paquet oui la joint aux paquets.
python capsuleforge.py traduire fiabilite --langue en [--moteur aucun|argos|deepl]
    Écrit ou complète data/capsuleforge/fiabilite/traductions/en.yaml (source, cible, relu) ; le moteur pré-remplit.
python capsuleforge.py traduire fiabilite --langue en --importer
    Recopie les traductions dans chapitre.yaml (textes {fr: …, en: …}) : sous-titres et voix dans cette langue.
python capsuleforge.py traduire fiabilite --langue en --relire
    Écran de relecture dans le navigateur : original, diapositive et son à côté ; « Fait » valide et passe au
    suivant, « Zap » passe sans changer le statut ; enregistrement continu ; bouton « Importer dans le chapitre ».
python capsuleforge.py video capture.mp4 --chapitre fiabilite --section partie/section [--son audio.mp4] [--titre "…"]
    Importe une vidéo (enregistrement d'écran, export ActivePresenter, clip) : compressée dans videos/, découpée
    en pas aux silences, chaque pas avec son image d'affiche et son son (transcription et relecture comme une diapo).
python capsuleforge.py filmer tuto1 --section principale/demo --titre "Démo" [--webcam] [--ecran 1] [--micro NOM]
    Filme l'écran, le micro (et la webcam) en même temps, puis importe la vidéo en pas (webcam = caméo).
    Ctrl+Maj+P pause, Ctrl+Maj+F (ou Entrée) fin. « filmer --appareils » liste écrans, caméras et micros ;
    « filmer --tester-micro [NOM] » écoute le micro 4 s et dit si le niveau de la voix convient.

scripts.capsuleforge.capsuleforge.commande_tolerante(argv: list[str]) → list[str]#

Remplace le premier argument par le nom exact de la commande qu’il abrège.

« con », « Vérifier » ou « verif » sont reconnus par leurs premières lettres, sans tenir compte des accents ni de la casse ; « v » désigne « verifier ». Renvoie argv inchangé si rien ne correspond ; arrête le programme (SystemExit) si l’abréviation est ambiguë.

scripts.capsuleforge.capsuleforge.trouver_capsule(nom: str) → pathlib.Path#

Renvoie le chemin du capsule.yaml désigné par nom.

nom peut être un fichier, un dossier ou un nom court cherché dans data/capsuleforge (sans tenir compte des accents ni de la casse ; un début de nom suffit s’il est unique). Le fichier renvoyé n’existe pas forcément (dossier d’un chapitre au format 2) ; SystemExit si rien ne correspond.

scripts.capsuleforge.capsuleforge.cmd_enregistrer(a)#

Enregistre une manipulation (commande enregistrer, Windows) puis affiche le contrôle de la capsule.

Le dossier de sortie est data/capsuleforge/<nom> pour un nom court ; il reçoit journal.jsonl, images/ et capsule.yaml.

scripts.capsuleforge.capsuleforge.cmd_construire(a)#

Construit le lecteur HTML d’une capsule (format 1) ou d’un chapitre (format 2), commande construire.

Si le dossier contient à la fois capsule.yaml et chapitre.yaml, l’option --lecteur choisit le format ; à défaut, le fichier modifié en dernier l’emporte. La sortie va par défaut dans <sorties>/capsuleforge/<nom>/ ; pour un chapitre, --scorm produit en plus les paquets SCORM.

scripts.capsuleforge.capsuleforge.pdfs_paquet(a, y: pathlib.Path) → list[dict]#

Versions du PDF à joindre aux paquets : celles cochées « dans le paquet » (_pdf.yaml), plus celle que demande --pdf (notée alors comme version, dans le paquet).

scripts.capsuleforge.capsuleforge.cmd_pdf(a)#

Fait une version du PDF d’une capsule à partir de son lecteur construit, sans la reconstruire (commande pdf).

Chaque réglage (--langue, --contenu, --notes) donne sa version, au nom explicite, dans le dossier pdf/ du lecteur (<capsule>_<langue>_<contenu>[_<notes>].pdf) ; une version n’écrase que celle qui a les mêmes réglages. --paquet oui la met dans les paquets SCORM (une par langue : l’autre en sort), --paquet non l’en retire ; la prochaine construction joint les versions cochées et les refait avec le lecteur à jour. --sans-refaire change seulement la case. --liste montre les versions. Avec --cours, le lecteur habillé de l’édition.

scripts.capsuleforge.capsuleforge.options_pdf(a) → dict | None#

Options --pdf de construire : {langue, contenu, notes}, ou None sans PDF.

scripts.capsuleforge.capsuleforge.empreinte_capsule(y: pathlib.Path, reglages: dict) → str#

Empreinte d’une construction : chapitre, médias du dossier (contenu ; taille et date au-delà de 4 Mo ou pour un fichier verrouillé), fiches d’exercices, réglages. Les dossiers de travail (sources, sauvegardes, enregistrements) et les verrous d’Office (~$…) ne comptent pas.

scripts.capsuleforge.capsuleforge.construire_pour_cours(a, y: pathlib.Path) → int#

construire --cours : capsule habillée pour l’édition, rangée comme version (capsules/<nom>/v1/) et inscrite au registre ; une construction identique (même capsule, mêmes médias, même habillage) n’en crée pas.
