scripts.forge.forge#

Forge E-Learning — Atelier : une page dans le navigateur qui lance les outils Forge sans ligne de commande.

Double-clic sur Forge.bat (racine du dépôt), ou python scripts/forge/forge.py [--port 8770] [--sans-navigateur].

L’atelier ne refait aucun calcul : chaque bouton lance une commande Forge existante (build.py, capsuleforge, quizforge, diagforge) dans un sous-processus et affiche son journal. Il ne lance que des actions connues, avec des options vérifiées (jamais une ligne de commande libre). Le serveur n’écoute que sur cet ordinateur (127.0.0.1), refuse les requêtes venues d’un autre site (serveur_local) et demande un jeton, tiré au lancement, pour toute action.

Routes :

GET / la page (atelier.html) GET /api/etat état du poste, profils, version GET /api/exoforge/fiches fiches ExoForge trouvées (exemples et data/exoforge) GET /api/capsules capsules de data/capsuleforge GET /api/capsule/<nom> état d’une capsule, section par section (capsules.detail) GET /api/quizforge/classeurs, /api/diagforge/dossiers listes des écrans Questions et Bilans GET /api/reglages réglages de l’atelier (data/_atelier/reglages.json) GET /api/taches résumé des tâches de la séance GET /api/tache/<id>?depuis=n lignes du journal d’une tâche à partir de la n-ième GET /dist/<chemin> fichiers construits (essayer un exercice, ouvrir un lecteur) POST /api/lancer {action, params} : lance une tâche POST /api/envoyer {id, ligne: pause|fin} : commande envoyée à une tâche qui l’accepte (filmer) GET /api/appareils écrans, caméras et micros (filmer) POST /api/arreter {id} : arrête une tâche POST /api/parcourir {dossier?, types?} : dialogue de fichiers de Windows, renvoie le chemin choisi POST /api/montrer {chemin} : ouvre l’explorateur sur un fichier ou un dossier du dépôt POST /api/ouvrir {chemin} : ouvre un fichier du dépôt avec son programme (Excel, navigateur…) POST /api/reglages {reglages: {profil?, diaporamas?: {}, oublier_diaporama?, retirer_classeur?}} : enregistre les réglages (GET et POST /api/reglages donnent aussi absents : les chemins retenus introuvables) POST /api/quitter arrête l’atelier (refusé si une tâche tourne, sauf {forcer: true}) POST /api/depart la page se ferme : arrêt dans 4 s si elle ne revient pas et qu’aucune tâche ne tourne

Met au premier plan la fenêtre qui vient de s’ouvrir.

explorateur : une fenêtre d’explorateur nouvelle, ou déjà ouverte sur le dossier titre ; sinon : une fenêtre dont le titre contient titre (nom du fichier ouvert dans Excel, le navigateur…), nouvelle de préférence.
