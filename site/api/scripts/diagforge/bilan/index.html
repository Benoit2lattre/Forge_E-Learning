scripts.diagforge.bilan#

QuizForge — DiagForge : bilan des résultats d’un test Moodle (exports « Notes » et « Réponses »).

Usage

python quizforge.py bilan <dossier ou fichiers> [-q questions.xml] [-t toutes|premiere|derniere|meilleure] [-s sortie.xlsx]

Lit les exports du rapport de test Moodle, en anglais ou en français, en CSV ou en XLSX :

  • « Notes » (Grades) : note de chaque tentative et note de chaque position (Q. 1 /1,00…) ;

  • « Réponses » (Responses), de préférence avec « Texte de la question » et « Bonne réponse » cochés : indispensable quand le test tire des questions au hasard (Q. 1 désigne alors une position, pas une question).

Les deux sont réunis tentative par tentative (courriel, début, fin, durée). L’export XML des questions (facultatif) donne le nom de chaque question et ses options (leurres jamais choisis). L’export « Statistiques » de Moodle n’est pas utilisé pour les calculs : les indicateurs sont recalculés ici, son résumé n’est affiché que pour comparaison.

Produit un classeur : Synthèse, Questions, Réponses, Éléments, Étudiants, Tentatives, et selon les données À revoir, Tirage, Rétention, Par erreur, Groupes, Par tag / type / catégorie ; ainsi qu’une fiche du professeur (HTML) et des images pour les étudiants (voir bilan_sorties).

Functions#

plancher_difficulte(k)

Renvoie la réussite sous laquelle une question à k options est « très difficile ».

lecture_discrimination(r, reussite)

Renvoie la lecture de la discrimination item-reste r : « à revoir », « faible », « correcte », « très bonne » ou « peu fiable ».

alpha_cronbach(colonnes)

Calcule l'alpha de Cronbach, ou None s'il n'est pas calculable.

alpha_ramene(alpha, k[, cible])

Applique la formule de Spearman-Brown : alpha d'un test de même qualité allongé (ou raccourci) de k à cible questions.

cle_texte(t) → str

Renvoie une clé de comparaison : sans accents, en minuscules, lettres et chiffres seulement.

propre(t) → str

Renvoie le texte sans balises HTML, entités décodées, espaces insécables et multiples réduits.

nombre(t)

Lit un nombre écrit à l'anglaise ou à la française (virgule, espaces, %) ; renvoie None si ce n'en est pas un.

duree_s(t)

Convertit une durée Moodle (« 3 mins 20 secs », « 1 heure 5 min »…) en secondes ; None si rien n'est reconnu.

date(t)

Convertit une date Moodle en datetime (sinon None).

pearson(x, y)

Renvoie le coefficient de corrélation de Pearson, ou None (moins de 3 points ou variance nulle).

lire_table(p)

Lit un export CSV ou XLSX et renvoie ses lignes non vides (listes de chaînes).

colonnes(entete)

Repère le rôle de chaque colonne d'un en-tête d'export Moodle.

nom_du_test(stem) → str

Extrait le nom du test d'un nom de fichier : « MMC-Quizz1_SMA-grades » → « Quizz1_SMA ».

groupe_du_test(test) → str

Extrait le groupe d'un nom de test : « Quizz1_SMA » → « SMA » (suffixe court après le dernier _), sinon "".

lire_exports(fichiers, avert[, moodle])

Lit les exports « Notes » et « Réponses » et renvoie la liste des tentatives (dictionnaires).

lire_banque_xml(xmls)

Lit les exports XML Moodle des questions et renvoie la banque (liste de dictionnaires).

completer_banque_yaml(chemins, banque)

Complète la banque avec les banques YAML de QuizForge (convertir → <classeur>_banque.yaml).

scripts.diagforge.bilan.plancher_difficulte(k)#

Renvoie la réussite sous laquelle une question à k options est « très difficile ».

C’est environ le hasard + 0,10 (slepkov2021 : 0,43 à 3 options, 0,35 à 4, 0,30 à 5 ; 0,60 à 2 options, par extension), jamais moins de 0,30 ; 0,30 si le nombre d’options est inconnu.

scripts.diagforge.bilan.lecture_discrimination(r, reussite)#

Renvoie la lecture de la discrimination item-reste r : « à revoir », « faible », « correcte », « très bonne » ou « peu fiable ».

« Peu fiable » quand la réussite est hors de l’intervalle fiable_min – fiable_max de SEUILS ; chaîne vide si r est None.

scripts.diagforge.bilan.alpha_cronbach(colonnes)#

Calcule l’alpha de Cronbach, ou None s’il n’est pas calculable.

colonnes : une liste de notes par question, mêmes tentatives dans le même ordre.

scripts.diagforge.bilan.alpha_ramene(alpha, k, cible=50)#

Applique la formule de Spearman-Brown : alpha d’un test de même qualité allongé (ou raccourci) de k à cible questions.

Renvoie None si alpha est absent, négatif ou nul, ou si k < 2.

scripts.diagforge.bilan.analyser(tent, banque, avert)#

Calcule les statistiques par question à partir des tentatives retenues.

Identifie chaque question (par la banque, sinon par le début de son texte, sinon par sa position), puis calcule réussite, discrimination item-reste, répartition des réponses, alertes et détail des réponses composées. Renvoie (questions, reponses, elems, obs, infos) ; obs et infos sont les observations et informations par question, reprises par les autres analyses.

scripts.diagforge.bilan.indicateurs(tent)#

Calcule les indicateurs du test comme Moodle, sur les tentatives entièrement notées.

Moyenne, médiane, écart-type (échantillon), asymétrie, aplatissement, cohérence interne (alpha de Cronbach sur les positions), alpha ramené à 50 questions, ratio d’erreur, erreur type, en % de la note maximale. Renvoie {} s’il y a moins de 4 tentatives.

scripts.diagforge.bilan.alpha_par_tag(obs, infos, n_min=10)#

Calcule l’alpha de Cronbach par tag (au moins 3 questions), sur les tentatives notées à toutes les questions du tag.

Renvoie [(tag, alpha, k, n)] ; alpha vaut None si moins de n_min tentatives contiennent toutes les questions (tirage au hasard). Les tags portés par presque toutes les questions sont ignorés.

scripts.diagforge.bilan.etudiants(tent_toutes)#

Renvoie une ligne par étudiant : notes (première, dernière, meilleure, moyenne), durée médiane et remarques.

Signale les tentatives très rapides et faibles (réponses au hasard ?) et les tentatives à corriger. Les lignes sont triées par nom puis prénom.

scripts.diagforge.bilan.bilan(cibles, xml=None, mode='toutes', sortie=None, couleur=COULEUR_PRINCIPALE, roster=None, images=True, tirage=None)#

Produit le bilan complet d’un test et renvoie le chemin du classeur.

  • cibles : dossiers ou fichiers d’exports Moodle ;

  • xml : banques de questions (XML ou YAML, fichiers ou dossiers), sinon celles trouvées dans cibles ;

  • mode : tentatives retenues (voir choisir_tentatives()) ;

  • roster : listes d’étudiants avec leur groupe ;

  • images : produire les graphiques pour les étudiants ;

  • tirage : mode de tirage déclaré dans le profil.

Écrit bilan_<test>.xlsx (ou sortie), la fiche du professeur …_fiche_prof.html et, si demandé, le dossier …_images. Quitte le programme si aucun export ou aucune tentative n’est lu.
