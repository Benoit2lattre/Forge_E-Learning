# Pourquoi l'estompage marche (Renkl et al., 2004)

Renkl, A., Atkinson, R. K. et Große, C. S. (2004). How fading worked solution steps works: A cognitive load perspective. *Instructional Science*, 32(1-2), 59-82. [DOI](https://doi.org/10.1023/B:TRUC.0000021815.74806.f6)

**En une phrase.** Ce n'est pas la position de l'étape retirée (première ou dernière) qui compte, mais le principe qu'elle mobilise : les étudiants apprennent surtout les principes dont l'étape leur a été laissée ; l'estompage réduit aussi les blocages improductifs.

## Ce que fait l'étude

- **Expérience 1** : 123 étudiants en psychologie, tirés au sort dans un plan 2 × 2 : principe estompé (complémentaire ou multiplication) × position (première ou dernière étape) ; environ 60 minutes ; post-test par principe.
- **Expérience 2** : estompage contre paires exemple-exercice, avec verbalisation à voix haute, pour observer les auto-explications, les blocages et les événements improductifs.

## Résultats

- **Exp. 1** : pas d'effet de la position (F < 1 pour l'interaction position × principe) ; interaction nette entre principe estompé et principe testé (F(1,119) = 8,…) : on apprend mieux le principe dont l'étape a été laissée à faire.
- **Exp. 2** : pas plus d'auto-explications productives avec l'estompage, mais moins d'événements improductifs, ce qui accompagne de meilleurs résultats (résumé).

## Avis critique

**Apport.** Corrige l'interprétation de Renkl et al. (2002) : l'important est le principe retiré. Pour un générateur d'exercices, cela veut dire choisir les étapes à faire selon les objectifs.

**Points forts**
- Plan factoriel qui sépare position et principe.
- Mesure des processus par verbalisation.

**Réserves**
1. **Importante** — Laboratoire, une séance, deux principes de probabilités.
2. **Importante** — Expérience 2 de petite taille (protocoles de verbalisation) ; résultat sur les processus plutôt que sur les résultats.
3. **Mineure** — Étudiants en psychologie.
