# _static

Images communes aux modes d'emploi et au site.

| Dossier | Contenu |
| --- | --- |
| `identite/` | logos, icônes (jour / nuit, toutes tailles), bandeaux de Forge E-Learning, QuizForge, ExoForge, DiagForge et CapsuleForge ; les fichiers `*_favicon.svg` sont les icônes sans étincelles ni bordure, pour les petites tailles |
| `identite/formats/` | icônes, logos et bandeaux des formats (SCORM, XML, HTML5, H5P, LMS), planche `formats_jour.png` / `formats_nuit.png`, bandeau de la démarche en sept étapes |
| `captures/quizforge/` | classeur modèle, assistant `QuizForge.bat`, pointeur de zones, import XML et question sur image dans Moodle |
| `captures/exoforge/` | exercices construits (profils Ecole1 et Delattre), dépôt du paquet SCORM dans Moodle |
| `captures/moodle/` | bac à sable public de Moodle (connexion, accueil) |
| `captures/diagforge/` | images pour les étudiants et fiche du professeur, sur la promotion fictive |
| `captures/moodle_exports/` | écrans d'export des résultats et de choix des questions (bac à sable : aucun étudiant réel) |

Les captures montrent uniquement des données fictives. Les captures d'écran du navigateur sont recadrées sur la page (sans barre de favoris ni onglets) ; les originaux restent dans `data/sources/captures_originales/`, non publié.
