# Animation contre image fixe (Höffler et Leutner, 2007)

Höffler, T. N. et Leutner, D. (2007). Instructional animation versus static pictures: A meta-analysis. *Learning and Instruction*, 17(6), 722-738. [DOI](https://doi.org/10.1016/j.learninstruc.2007.09.013)

**En une phrase.** Sur 76 comparaisons, une animation fait mieux apprendre qu'une image fixe équivalente (d = 0,37), surtout quand elle montre le contenu lui-même (d = 0,40) et non un décor (d = 0,05) ; pour CapsuleForge, animer ce qui bouge et proscrire l'animation décorative.

## Ce que fait l'étude

- **Corpus** (p. 725) : 57 articles examinés, 26 retenus (1973-2003) ; critères : animation contre image fixe, pas de mélange des deux, peu ou pas d'interactivité, contenus à peu près équivalents.
- **Analyse** (p. 726) : d de Hedges, effets aléatoires ; comparaisons multiples d'une même étude gardées, mais avec un poids ajusté (effectif divisé par le nombre de comparaisons) ; contrastes corrigés par Holm-Bonferroni.
- **Modérateurs** (p. 727) : rôle de l'animation (représentationnelle ou décorative), type de connaissance (procédurale-motrice, déclarative, résolution de problèmes), vidéo ou animation informatique, réalisme, texte d'accompagnement, signalement dans les images fixes, domaine. Le temps passé n'a pu être codé que dans 7 études.

## Résultats

- **Effet global** (p. 727) : d = 0,37, IC95 [0,25 ; 0,49] ; 54 comparaisons sur 76 positives ; 21 significatives en faveur de l'animation, 2 en faveur de l'image ; hétérogénéité forte (Q = 425,09, ddl = 75) ; fail-safe N = 2736.

- **Confusions signalées par les auteurs** (p. 731-732) : les 5 comparaisons procédurales-motrices et 11 des 12 vidéos sont représentationnelles ; une fois les animations décoratives retirées, l'écart vidéo contre informatique disparaît (0,85 contre 0,68, p = 0,395).
- **Texte et signalement** (p. 732-733) : ni le texte d'accompagnement ni les repères dans l'image fixe ne modifient significativement l'avantage de l'animation.

## Avis critique

**Apport.** Méta-analyse fondatrice : l'animation a un avantage moyen réel, à condition de représenter le contenu ; c'est la base de la règle « animer ce qui change ».

**Points forts**
- Critère d'équivalence d'information entre les deux versions (p. 725), qui écarte les comparaisons inéquitables.
- Poids ajustés pour les comparaisons dépendantes (p. 726, note 1).
- Les auteurs analysent eux-mêmes les confusions entre modérateurs.

**Réserves**
1. **Importante** — Le résultat le plus cité (procédural-moteur d = 1,06) repose sur 5 comparaisons, dont 3 de Spangenberg (1973) sur le remontage d'une mitrailleuse (p. 731, 733) ; berney2016 exclut cette étude (animation non informatique) et ne retrouve pas d'avantage net pour le procédural.
2. **Importante** — Biais de publication évalué par le seul fail-safe N (p. 727) ; intervalle de prédiction non rapporté malgré une forte hétérogénéité.
3. **Importante** — Temps d'étude non contrôlé : codé dans 7 études seulement (p. 727) ; une animation peut faire passer plus de temps sur le contenu.
4. **Mineure** — Études anciennes (1973-2003), technologies d'animation datées ; berney2016, avec 41 expériences de plus, obtient un effet plus faible (g = 0,23).

**Niveau de preuve**

| Affirmation | Niveau | Raison |
| --- | --- | --- |
| Une animation représentationnelle fait mieux qu'une image fixe équivalente | A | Méta-analyse confirmée par berney2016 sur un corpus élargi ; effet modeste |
| Une animation décorative n'apporte rien | B | 17 comparaisons, cohérent avec le principe de cohérence (fyfield2022) |
| L'animation est surtout utile pour les gestes procéduraux | C | 5 comparaisons, dominées par une étude, non retrouvé par berney2016 |

**Transférabilité** : forte pour la règle « représentationnel, pas décoratif » ; 65 % des études portent sur des étudiants de premier cycle et 39 comparaisons sur la physique.

**Pour conclure, il faudrait** vérifier dans une capsule de mécanique (cinématique d'un mécanisme) qu'une animation représentationnelle fait mieux qu'une suite d'images fixes à temps d'étude égal.

## Pour Forge

- **CapsuleForge** : animation seulement quand le mouvement est le contenu ; pas d'animation décorative (niveau B).
- **CapsuleForge** : vidéo ou animation pour les gestes de manipulation (TP, montage, mesure) (niveau C).
- **CapsuleForge** : animations schématiques plutôt que réalistes (niveau D).
