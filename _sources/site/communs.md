# Éléments communs : style et profils

Les outils partagent deux éléments :

- un **style générique** ({doc}`../style/README`) : il ne contient aucune couleur d'établissement ; chaque couleur passe par un **rôle** (couleur principale, réponse juste, réponse fausse, définition, résultat, piège…), en CSS pour les pages et en LaTeX pour les formules ;
- des **profils** ({doc}`../profils/README`) : un profil donne la couleur de chaque rôle, les polices, le jeu de couleurs LaTeX et les réglages par défaut de QuizForge (barème, types de questions, langues, tirage des questions). Deux profils sont fournis : `Delattre` (profil de l'auteur, par défaut) et `Ecole1` (établissement d'exemple, à copier). Un profil privé se range dans `data/profils/`, non publié.

La bibliographie (dossier `reference/`), troisième élément commun, a sa propre partie du site.
